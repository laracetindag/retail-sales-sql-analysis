RETAIL SALES ANALYTICS — BEGINNER SQL PORTFOLIO PROJECT

All data is fictional. Compatible with DB Browser for SQLite on Mac.

QUICK START
1. Install DB Browser for SQLite: https://sqlitebrowser.org/dl/
2. Open retail_sales.db using Open Database.
3. Select Browse Data to explore products, customers, sales and sale_details.
4. In Execute SQL, open analysis_queries.sql. Select and run one SELECT statement at a time.
5. Compare results with the included CSV files.

FILES
retail_sales.db — ready-to-use database
retail_sales_project.sql — recreate database from scratch
analysis_queries.sql — five analysis queries
*.csv — query results, ready for Excel or Power BI

BUSINESS QUESTIONS
Which products and stores generate the most revenue? Who spends the most? Which categories produce the most gross profit? How does monthly revenue change?

Gross profit here means sales revenue minus product costs; it excludes operating expenses, taxes and returns. Small fictional dataset is for learning, not real business inference.
